
# ระบบฟางข้าว - กล้าแกร่ง

แดชบอร์ดเพื่อประเมินปริมาณฟางข้าวในจังหวัดนครสวรรค์

## วิธีใช้งานบน Streamlit Cloud

1. สมัครหรือเข้าสู่ระบบ https://streamlit.io/cloud
2. สร้าง GitHub repository ใหม่ แล้วอัปโหลดไฟล์ทั้งหมดจาก zip นี้
3. เชื่อม GitHub เข้ากับ Streamlit Cloud แล้วเลือกไฟล์ `app.py` เป็น entry point
4. กด Deploy

เพียงเท่านี้ คุณจะได้เว็บแดชบอร์ดพร้อมใช้งาน (เช่น https://yourname.streamlit.app)
